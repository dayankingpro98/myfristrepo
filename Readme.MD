# 🚀 تلگرام پروکسی MTProto برای Railway

یک پروکسی MTProto تلگرام با رابط وب که روی Railway قابل استقرار است.

## ✨ امکانات

- ✅ پروکسی MTProto رسمی تلگرام
- ✅ رابط کاربری وب برای دریافت لینک اتصال
- ✅ کپی خودکار اطلاعات با یک کلیک
- ✅ پشتیبانی از دامنه اختصاصی Railway
- ✅ اتصال مستقیم با یک کلیک در تلگرام
- ✅ SSL رایگان
- ✅ رایگان و متن‌باز

## 📋 پیش‌نیازها

- حساب [GitHub](https://github.com)
- حساب [Railway](https://railway.app)
- تلگرام (نسخه موبایل یا دسکتاپ)

## 🛠️ راهنمای نصب

### مرحله ۱: آپلود به GitHub

1. یک ریپازیتوری جدید در GitHub بسازید
2. فایل‌های پروژه رو آپلود کنید:
   - `main.py`
   - `requirements.txt`
   - `Dockerfile`
   - `railway.toml`

### مرحله ۲: اتصال به Railway

1. به [railway.app](https://railway.app) بروید
2. با حساب GitHub لاگین کنید
3. روی **"New Project"** کلیک کنید
4. **"Deploy from GitHub repo"** رو انتخاب کنید
5. ریپازیتوری خودتون رو انتخاب کنید

### مرحله ۳: تنظیم متغیرهای محیطی

1. روی پروژه کلیک کنید
2. به تب **"Variables"** بروید
3. این متغیرها رو اضافه کنید:

| Variable | Value | توضیحات |
|----------|-------|---------|
| `SECRET` | یه رمز تصادفی ۳۲ رقمی hex | سکرت پروکسی (مثلاً: `a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6`) |
| `PORT` | `8443` | پورت سرور |

**⚠️ نکته مهم:** حتماً یه سکرت تصادفی قوی بسازید. می‌تونید از این سایت استفاده کنید: [random.org](https://www.random.org/cgi-bin/randbyte?nbytes=16&format=h)

### مرحله ۴: دیپلوی

1. Railway خودکار شروع به دیپلوی می‌کنه
2. چند دقیقه صبر کنید تا build تموم بشه
3. بعد از تموم شدن، دامنه‌ای مثل `xxx.railway.app` بهتون میده

### مرحله ۵: دریافت لینک پروکسی

1. روی دامنه‌ای که Railway بهتون داد کلیک کنید
2. صفحه‌ای باز میشه که اطلاعات پروکسی رو نشون میده
3. روی **"اتصال مستقیم در تلگرام"** کلیک کنید
4. یا اطلاعات رو دستی کپی کنید و توی تلگرام وارد کنید

## 📱 نحوه اتصال در تلگرام

### روش ۱: اتصال با لینک (ساده‌ترین)
1. لینک `tg://proxy?...` رو کپی کنید
2. توی مرورگر باز کنید یا مستقیم توی تلگرام paste کنید

### روش ۲: اتصال دستی
1. تلگرام → Settings → Data and Storage → Proxy Settings
2. **Add Proxy** → **MTProto**
3. این مقادیر رو وارد کنید:
   - **Server:** دامنه Railway (مثل `xxx.railway.app`)
   - **Port:** `8443`
   - **Secret:** سکرتی که تنظیم کردید

## 🔧 عیب‌یابی

### مشکل: سایت باز نمیشه
**راه‌حل:**
- مطمئن بشید دیپلوی تموم شده
- از تب Deployments، لاگ‌ها رو چک کنید
- مطمئن بشید متغیر `PORT` رو تنظیم کردید

### مشکل: پروکسی وصل نمیشه
**راه‌حل:**
- مطمئن بشید سکرت رو درست وارد کردید
- سعی کنید دوباره لینک رو باز کنید
- یه بار سرور رو ری‌استارت کنید (Redeploy)

### مشکل: خطای build
**راه‌حل:**
- فایل‌ها رو چک کنید که درست آپلود شدن
- لاگ‌های build رو ببینید
- `Dockerfile` و `requirements.txt` مطمئن باشید

## 🌐 تنظیمات پیشرفته

### استفاده از دامنه اختصاصی
اگه دامنه خودتون رو دارید:
1. توی Railway، به تنظیمات سرویس برید
2. **Networking** → **Custom Domain** رو انتخاب کنید
3. دامنه خودتون رو اضافه کنید

### تغییر پورت
اگه می‌خواید پورت عوض بشه:
1. توی Variables، `PORT` رو عوض کنید
2. Railway ری‌دیپلوی می‌کنه
